Open Duck Mini でダンスと高度な動きに挑む

学習済みの歩行の上に制御を重ねて ／ Physical AI 応用編1 最終課題 説明資料(短縮版)／ MuJoCo Playground + PPO、シミュレーターのみ
作成日: 2026-10-29 ／ アカウント ID: 142340

1. 目的とやり方

小型二足歩行ロボット Open Duck Mini v2 に、音楽に合わせたダンスや、ジャンプ・スキップのような高度な動きをさせることが目的。まず強化学習(PPO)で歩行を学習し、次に、学習済みの歩きは変えずに、上に「速度指令を毎回計算する制御」を重ねて新しい動きをさせた。追加の学習は要らない。

2. 結果の一覧(すべて自分で測った値、各実験は乱数の種 1 本)

項目結果判定
歩行前後・横の速度追従の報酬を 2 倍にすると、歩き始めが約 1,100 万ステップ早く(39.6M → 28.8M)、5,000 万ステップ時点の速さが 0.056 → 0.119 m/s(約 2.1 倍)。成功
後退・旋回・横歩き報酬 2 倍のまま学習を 5,000 万 → 1.3 億ステップにすると、10 秒の移動が後退 0.01 → 0.54 m、横歩き左 0.24 → 0.60 m・右 0.20 → 0.46 m、旋回 左 101 → 342°・右 30 → 243°。全基準の同時達成はなし。部分的成功
道案内役4 つの目標点すべてに到達(転倒なし)。成功
サッカー調整した 5 か所で 4 回、調整に使っていない 3 か所で 3 回ゴール。1 回は転倒。部分的成功
ダンス2 曲とも約 1 分、転倒なし。首を振りながら回ると回転がほぼ止まることも分かった。成功
ジャンプ手で書いた「しゃがむ → 伸ばす」72 通りで、足の裏の浮きは最大 0.15 cm(基準 1 cm)。失敗
スキップ風の歩き足を 8 cm 上げる手本で 1 億ステップ学習したが、足の高さは 0.43 cm(基準 2.5 cm)。手本をまねなかった。失敗

3. 学習の長さと報酬の効果(後退・横歩き・旋回)

変えた報酬は tracking_lin_vel(前後・横方向の速度への追従)の 1 つだけで、旋回の報酬など他は公式のまま。

4. 検証と限界

  • 検証: 測る前に成功・失敗の基準を決めて記録した(失敗も残した)。書き出した ONNX と JAX の方策の出力は、最大の差 5.1e-07 で一致(許容 1e-4)。
  • 限界: 各設定の学習は 1 回(乱数の種を変えた繰り返しなし)。ランダム化への耐性は測っていない。サッカーの調整は 5 か所に合わせた。実機では試していない。
  • 費用と再現: AWS g6.xlarge で累計約 3 ドル。手順・数値の全記録は GitHub リポジトリの README と docs/experiments.md(詳しい説明資料は別紙)。
